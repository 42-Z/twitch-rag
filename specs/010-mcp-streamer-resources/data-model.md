# Модель данных: общая информация о стримере для ассистента

**Дата**: 2026-11-19

**Спецификация**: [spec.md](./spec.md) | **Исследование**: [research.md](./research.md)

## Сущности

### Запись канала (`channel`)

Хеш в Upstash Redis. Прежние поля не меняются (`src/shared/registry.ts:19-34`); добавляется одно.

| Поле | Тип | Обязательное | Смысл |
|---|---|---|---|
| `streamerInfo` | string | нет | Сведения для разбора: имена, собеседники, словечки. Уходят в инструкцию документа. **Не меняется.** |
| `agentStreamerInfo` | string | нет | Общая информация о стримере для ассистента. Уходит только в ресурс MCP. **Новое.** |

**Правила поля `agentStreamerInfo`.**

- Пустая строка и отсутствие поля равнозначны «не задано». Поле из одних пробелов читается как пустое (`trim`).
- Предел длины — 20 000 знаков, как у `streamerInfo` (`src/worker/routes/channel.ts:47`).
- Поле не участвует в составлении документа: `buildDocumentSystemPrompt` его не читает.
- Поле не подставляется вместо пустого: если `agentStreamerInfo` не задано, ресурс отсутствует, даже когда `streamerInfo` заполнено.
- `setChannel` перечисляет поля поимённо (`src/shared/registry.ts:161-171`) и новое поле не трогает; подключение канала его не затирает.
- Новый метод `Registry.setAgentStreamerInfo` пишет только это поле.

### Сводка канала для страницы (`ChannelSummary`)

Читается браузером публичным токеном только на чтение (`src/ui/lib/registry.ts:50-57`, `:192-207`). К прежним полям добавляется:

| Поле | Тип | Смысл |
|---|---|---|
| `agentStreamerInfo` | string, необязательное | Текущий текст для показа в разделе MCP и в форме управления |

### Ресурс MCP

Не хранится; собирается из `agentStreamerInfo` на каждый запрос.

| Свойство | Значение |
|---|---|
| Адрес (`uri`) | `streamer://info` — постоянный, при правке текста не меняется |
| Имя (`name`) | `streamer_info` |
| Название (`title`) | «Общая информация о стримере» |
| Описание (`description`) | «Кто такой стример и о чём канал: общие сведения для ассистента» |
| Тип (`mimeType`) | `text/plain` |
| Содержимое | Текст `agentStreamerInfo` без ведущих и замыкающих пробелов, без обёртки инструкции, целиком |
| Когда отсутствует | Поле пустое или канал не подключён: в перечне ресурса нет, чтение — ошибка «ресурс не найден» |

### Запрос записи

`PUT /api/agent-streamer`

| Часть | Значение |
|---|---|
| Заголовок | `Authorization: Bearer <токен владельца>` |
| Тело | `{ "info": string }`, не длиннее 20 000 знаков |
| Успех | `200 { "saved": true }`; пустая строка сохраняется как «не задано» |
| Отказ без токена | `401 unauthorized` |
| Отказ на тело | `400 invalid_input` с человеческим текстом |

## Состояния

| Было | Действие | Стало |
|---|---|---|
| Поле пустое | Владелец сохранил текст | Следующий перечень содержит ресурс; чтение отдаёт текст |
| Поле заполнено | Владелец сохранил другой текст | Следующее чтение отдаёт новый текст; адрес ресурса прежний |
| Поле заполнено | Владелец сохранил пустую строку | Следующий перечень ресурса не содержит; чтение — «не найден» |
| Канал не подключён | — | Поля нет, ресурса нет; инструменты работают как прежде |
| Канал подключён | Сменили отслеживаемый канал | Поле сохраняется: `setChannel` его не затирает — как и прежнее `streamerInfo` |

## Что не меняется

- `streamerInfo` и его место в системной инструкции разбора.
- Инструменты MCP и их ответы.
- Схема реестра для записей трансляций, векторная база, документы, программа конвейера.
- Модель доступа: MCP-сервер публичный, без авторизации.
