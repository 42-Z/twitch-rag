# Контракт: ресурс со сведениями о стримере

**Дата**: 2026-11-19 | **Спецификация**: [spec.md](../spec.md) | **Инструменты MCP**: [001/contracts/mcp-server.md](../../001-stream-archive-rag/contracts/mcp-server.md)

Сервер тот же, что обслуживает `/mcp`: Streamable HTTP без состояния, без авторизации. Контракт дополняет [`mcp-server.md`](../../001-stream-archive-rag/contracts/mcp-server.md): инструменты не меняются, добавляется один ресурс.

## Возможность

Сервер объявляет `resources: { listChanged: false }`. Подписок и уведомлений об изменениях нет: сервер без состояния, клиент видит правку при следующем обращении. Перечень и содержимое считаются на момент запроса.

## Ресурс

| Поле | Значение |
|---|---|
| `uri` | `streamer://info` |
| `name` | `streamer_info` |
| `title` | Общая информация о стримере |
| `description` | Кто такой стример и о чём канал: общие сведения для ассистента |
| `mimeType` | `text/plain` |

## `resources/list`

- Поле `agentStreamerInfo` непустое — в ответе ровно один ресурс с полями из таблицы.
- Поле пустое, отсутствует или канал не подключён — `{ "resources": [] }`.
- Хранилище недоступно — ошибка по правилам протокола; пустой список вместо ошибки не подставляется.
- Ресурсов шаблонов нет: `resources/templates/list` возвращает пустой список.

## `resources/read`

- Ресурс есть — `contents` содержит один текстовый элемент: `uri: "streamer://info"`, `mimeType: "text/plain"`, `text` — сохранённый текст без ведущих и замыкающих пробелов, без обёртки инструкции, целиком в пределах 20 000 знаков.
- Поле пустое или канал не подключён — ошибка «ресурс не найден» (`-32602`, `data.uri`), пустой `contents` не возвращается.
- Хранилище недоступно — ошибка по правилам протокола; пустой текст или сведения из поля для разбора не подставляются.
- Текст меняется между запросами — каждое чтение отдаёт текущее значение; адрес ресурса не меняется.

## Пример

Заполненное поле:

```json
{
  "jsonrpc": "2.0",
  "id": 7,
  "result": {
    "contents": [
      {
        "uri": "streamer://info",
        "mimeType": "text/plain",
        "text": "5opka (пятёрка) — стример из Ростова-на-Дону. Канал про общение: истории из жизни, разборки с чатом, просмотр фильмов и видео, Minecraft, музыка."
      }
    ]
  }
}
```

Пустое поле — вместо `result`:

```json
{
  "jsonrpc": "2.0",
  "id": 8,
  "error": {
    "code": -32602,
    "message": "Resource not found",
    "data": { "uri": "streamer://info" }
  }
}
```

## Правила

- Ресурс только для чтения: через MCP текст не меняется; правка — на странице управления.
- Инструменты `search_knowledge`, `knowledge_stats`, `list_streams` и их ответы не меняются.
- Поле `streamerInfo` (для разбора) ресурсом не является и запасным источником не служит.
- Доступ — всем, кто подключается к серверу; токена нет.
