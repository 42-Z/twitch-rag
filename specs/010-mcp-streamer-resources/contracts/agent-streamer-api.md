# Контракт: запись общей информации о стримере для ассистента

**Дата**: 2026-11-19 | **Спецификация**: [spec.md](../spec.md) | **Ресурс**: [mcp-resource.md](./mcp-resource.md)

## `PUT /api/agent-streamer`

Владельческий путь: меняет общую информацию о стримере, которую получает ассистент. Прежнее поле для разбора не трогает.

**Заголовки**

| Заголовок | Значение |
|---|---|
| `Authorization` | `Bearer <APP_ADMIN_TOKEN>` |
| `Content-Type` | `application/json` |

**Тело**

```json
{ "info": "5opka (пятёрка) — стример из Ростова-на-Дону. Канал про общение: истории из жизни, разборки с чатом, Minecraft, музыка." }
```

| Поле | Тип | Обязательное | Ограничение |
|---|---|---|---|
| `info` | string | да | не длиннее 20 000 знаков |

**Ответ**

| Код | Тело | Когда |
|---|---|---|
| 200 | `{ "saved": true }` | Сохранено, в том числе пустая строка |
| 400 | `{ "error": { "code": "invalid_input", "message": "…" } }` | Нет поля `info`, не строка, длиннее предела |
| 401 | `{ "error": { "code": "unauthorized", "message": "…" } }` | Нет токена или он не подошёл |

Пустая строка — осознанное «не задано»: следующий перечень ресурсов её не покажет, чтение ответит «не найден». Обрезание текста при превышении предела не делается: запрос отвергается целиком.

## Хранение

- Хеш `channel`, поле `agentStreamerInfo`.
- `streamerInfo` (для разбора) не меняется и не читается этим путём.
- `setChannel` поле не затирает: подключение канала перечисляет только свои поля.

## Чтение страницей

Страница читает хеш `channel` публичным токеном только на чтение и получает `agentStreamerInfo` вместе с остальными полями. Отдельного публичного пути нет.
