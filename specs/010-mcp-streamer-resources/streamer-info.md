# Сведения о стримере 5opka для ассистента

Готовый текст для поля «Общая информация о стримере для ассистента». Собран из
открытых источников — биография на Википедии и в профильных изданиях, каталоги
стримеров, новостные заметки о канале. Ничего, чего не было бы в открытом
доступе.

Назначение — общие сведения для ассистента, подключённого по MCP. Это не
сведения для разбора: они остаются в прежнем поле «О стримере» и в документ
этот текст не попадает.

## Текст для поля

```
5opka (пятёрка, также «opka»; музыкальный псевдоним 6055) — российский стример Кирилл Баранов из Ростова-на-Дону. В эфире и в документах канала он — 5opka; зрители и собеседники зовут его также Кириллом и Кирюшей.

Канал про общение: многосерийные истории из жизни, разборки с чатом, просмотры фильмов и видео, Minecraft, музыка. 5opka — основатель серверов «СП» («Страна Подписчиков»). Главный мем канала — «42, братуха»: отсылка к «Автостопом по галактике», пародия на движение «52». Лауреат премии SLAY.

Постоянные собеседники и гости: Соня (sonasheka), Мафаня (mafanyaking), Buster, MellSher (Игорь) — соучредитель студии 5SM Sound, Ханов, Лаврик, Стинт (Stint), Дрейк (drakeoffc). В партиях в Dungeons & Dragons мастер — Владбер.

Свои названия и словечки: «пятёрка», «СП», «42, братуха», 5SM Sound, SLAY. Нарезки канала выходят у «Вырезок Пятёрки» и «Вселенной Пятёрки».
```

## Что сюда не вошло и почему

- **Даты рождения, точный адрес, состав семьи.** Для общих сведений они ничего
  не дают, а поле публично: его видит любой, кто подключается к серверу. Город
  указан, потому что он есть в открытых источниках и помогает опознанию.
- **Указания для распознавания.** «Buster в расшифровке звучит как „Бустер“» и
  подобное — работа прежнего поля для разбора; ассистенту нужны имена, а не
  правила их исправления.
- **Ники, которым не нашлось открытого соответствия.** «Аутсайдер», «Илюха»,
  «Валерчик», «Грибданил» в текст не попали: выдуманное опознание хуже
  отсутствующего.
- **Пересказ биографии.** Поле описывает канал и его окружение, а не жизнь
  стримера.

## Откуда

- `specs/002-document-quality/streamer-info.md` — прежний текст, собранный из
  открытых источников.
- Открытые источники о канале и стримере: биография, каталоги стримеров,
  новостные заметки.

**Что проверено.** Текст повторяет сведения, которые уже стоят в прежнем поле
для разбора; новых фактов в нём нет, кроме имён, уже известных по тому полю.
Точные ссылки на внешние источники в прежней работе не сохранились — перед
первой публикацией их стоит восстановить и сверить премию, студию и состав
собеседников.

## Как сохранить

Текст вставляется в поле «Общая информация о стримере для ассистента» в разделе
управления или отправляется на `PUT /api/agent-streamer` с токеном владельца.
Это действие над боевыми данными — выполняется после выпуска, в список задач не
входит.
