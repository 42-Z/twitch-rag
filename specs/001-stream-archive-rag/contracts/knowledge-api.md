# Контракт: HTTP API

**Дата**: 2026-09-14 | **Спецификация**: [spec.md](../spec.md) | **MCP**: [mcp-server.md](./mcp-server.md)

Один Worker обслуживает три вида обращений: статику интерфейса, знания для программных
клиентов и служебные операции владельца. Тела запросов и ответов — JSON в UTF-8, время —
ISO 8601 UTC, секунды — целые числа.

**Что через этот API не ходит**: список разобранных трансляций страница читает напрямую
из реестра своим read-only токеном, минуя Worker. Адрес реестра и этот токен попадают в
сборку интерфейса как публичные значения — токен разрешает только чтение, и документация
хранилища прямо допускает его раскрытие в веб-клиентах.

## Общий формат ошибки

```json
{
  "error": {
    "code": "vod_unavailable",
    "message": "Запись недоступна: она удалена или открыта только подписчикам.",
    "hint": "Проверьте ссылку или добавьте другую запись."
  }
}
```

Коды: `invalid_input`, `not_found`, `vod_unavailable`, `channel_not_set`,
`already_processed`, `upstream_unavailable`, `rate_limited`, `internal`.

## POST /api/knowledge/search

Главный контракт продукта. **Публичный, авторизации не требует** (FR-027), ограничен по
частоте (FR-028).

**Запрос**

```json
{
  "query": "что говорили про переход на новый движок",
  "topK": 5,
  "minScore": 0.35,
  "from": "2026-01-01",
  "to": "2026-09-01",
  "category": "Just Chatting"
}
```

| Поле | Тип | Обязательное | Правила |
|------|-----|--------------|---------|
| `query` | string | да | 1–1000 знаков после обрезки пробелов |
| `topK` | number | нет | 1–20, по умолчанию 5 |
| `minScore` | number | нет | 0..1, по умолчанию 0.35 |
| `from` / `to` | string | нет | границы даты эфира, `YYYY-MM-DD` |
| `category` | string | нет | точное имя категории |

**Ответ 200**

```json
{
  "found": true,
  "documents": [
    {
      "id": "2345678901:12",
      "topic": "Причины перехода на новый движок",
      "text": "Полный текст раздела…",
      "score": 0.82,
      "category": "World of Warcraft",
      "stream": {
        "vodId": "2345678901",
        "title": "Пятничный разбор кода",
        "publishedAt": "2026-03-14T18:03:00Z",
        "url": "https://www.twitch.tv/videos/2345678901?t=1h12m30s"
      },
      "startSeconds": 4350,
      "endSeconds": 4720
    }
  ],
  "stats": { "returned": 1, "latencyMs": 240 }
}
```

**Ответ при отсутствии знаний** — 200, не ошибка (FR-024):

```json
{ "found": false, "documents": [], "message": "В базе знаний нет сведений по этому вопросу." }
```

**Правила**

- `text` — раздел целиком, а не найденный кусок (FR-022). Дубликаты по разделу
  схлопываются: если два куска одного раздела попали в выдачу, раздел возвращается один
  раз с лучшей оценкой.
- Результаты отсортированы по убыванию `score`; ниже `minScore` не попадают.
- Запрос обслуживается независимо от того, идёт ли разбор (FR-026).
- Превышение частоты — 429 с кодом `rate_limited` и заголовком `Retry-After`.

## GET /api/knowledge/stats

Границы базы знаний: за какой период есть сведения, сколько трансляций и разделов.
Публичный, нужен ассистенту, чтобы честно говорить о пределах своих знаний.

```json
{
  "channel": "examplechannel",
  "streams": { "ready": 42, "skipped": 3 },
  "sections": 1834,
  "coverage": { "from": "2026-01-05T17:00:00Z", "to": "2026-09-12T21:30:00Z" },
  "categories": ["Just Chatting", "World of Warcraft"],
  "lastIndexedAt": "2026-09-12T23:40:00Z"
}
```

## GET /api/streams/:vodId/document

Документ трансляции целиком, из хранилища документов (FR-031). Отдаётся как
`text/markdown`. Бакет приватный, поэтому чтение идёт через Worker; ответ кэшируется —
документ неизменен после создания.

## POST /api/streams

Ручное добавление записи (FR-004). Требует токена владельца в заголовке
`Authorization: Bearer <APP_ADMIN_TOKEN>`.

Запрос: `{ "url": "https://www.twitch.tv/videos/2345678901" }` либо `{ "vodId": "2345678901" }`.

Ответ 202: `{ "vodId": "2345678901", "status": "processing" }`. Уже разобранная запись —
ошибка `already_processed`.

## DELETE /api/streams/:vodId

Удаление трансляции: разделы из векторной базы по префиксу, документ из хранилища,
запись из реестра (FR-033). Требует токена владельца.

Ответ: `{ "vodId": "2345678901", "deletedChunks": 137 }`.

## POST /api/internal/ingest-ready

Служебный вызов от бокса: куски аудио выложены, можно начинать обработку. Требует
общего секрета в заголовке `X-Ingest-Secret`; адрес и секрет передаются боксу при
запуске прогона.

```json
{
  "vodId": "2345678901",
  "title": "Пятничный разбор кода",
  "publishedAt": "2026-03-14T18:03:00Z",
  "durationSeconds": 25135,
  "categories": [{ "title": "World of Warcraft", "startSeconds": 0, "endSeconds": 13103 }],
  "chunks": [{ "index": 0, "key": "audio/2345678901/chunk-0000.m4a", "offsetSeconds": 0, "durationSeconds": 600 }]
}
```

Worker проверяет секрет, создаёт инстанс обработки и отвечает 202 с его идентификатором.
Повторный вызов для той же записи, уже находящейся в обработке, отвечает 200 и нового
инстанса не создаёт.

Отдельный вызов сообщает о неудаче бокса:

```json
{ "vodId": "2345678901", "failed": true, "code": "subscriber_only", "message": "Запись доступна только подписчикам" }
```

Такая запись помечается в реестре как пропущенная и больше не берётся (FR-006).

## GET /api/health

```json
{
  "status": "ok",
  "checks": { "redis": "ok", "vector": "ok", "blob": "ok", "r2": "ok", "openrouter": "ok", "twitch": "ok", "box": "ok" },
  "channel": "examplechannel",
  "lastCheckedAt": "2026-09-14T08:00:00Z"
}
```

`status` становится `degraded`, если любая проверка не `ok`. Показывается на странице,
чтобы отсутствие ключа или недоступность сервиса были видны сразу.

## Запуск по расписанию

Не эндпоинт, а обработчик расписания в том же Worker. Раз в час: получить список записей
канала, вычесть уже разобранные и пропущенные по реестру, взять самую раннюю
необработанную, запустить прогон в боксе с адресом `/api/internal/ingest-ready` и
секретом, записать в реестр состояние `processing`. За один запуск берётся одна запись —
чтобы одновременный разбор не съедал квоту процессорного времени бокса.

## Доступ

| Путь | Кто может |
|------|-----------|
| `/`, статика | все |
| `/api/knowledge/*`, `/mcp` | все, с ограничением частоты |
| `/api/streams/:vodId/document` | все |
| `POST /api/streams`, `DELETE /api/streams/:vodId` | владелец, по токену |
| `/api/internal/*` | бокс, по общему секрету |

Ограничение частоты применяется к публичным путям по адресу отправителя. Статика
обслуживается раньше Worker, чтобы исчерпание лимита не превращало страницу в ошибку.
