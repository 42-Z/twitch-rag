# Quickstart: проверка крупных разделов

**Feature**: [spec.md](./spec.md) | **Plan**: [plan.md](./plan.md)

Порядок проверки результата. Платные шаги помечены; запускаются только по согласию владельца и в пределах $2,0
([research.md](./research.md), §6).

## Часть 1. До выпуска (локально)

Предпосылки: Node ≥ 24.12, `npm ci`, в `.env` ключ OpenRouter.

1. **Базовый прогон** (платно, около $0,31): текущая инструкция на трёх длинных фрагментах.

   ```sh
   node --env-file=.env specs/007-stream-frames/research/scripts/measure-frames.ts \
     --transcript 2875806701-1200-5400 --frames 2875806701-1200-5400 --variants frames --tag base008 \
     --streamer-info-file <файл с полем «О стримере»>
   ```

   То же для `2872271642-4900-10500` и `2872271642-10500-16800`. Результат: файлы
   `document-frames-<метка>-base008-frames.json`; ожидаемо — средний раздел 108–166 с (research.md §3).

2. **Вариант правил** (платно, около $0,31): правка `PROMPT_RULES` и `PROMPT_EXAMPLES`, тот же прогон с меткой
   `v1008`, `v2008` и т. д. Сводка размеров — `specs/008-coarser-sections/research/scripts/section-sizes.mjs`, дополненный
   чтением JSON стенда.
   Ожидаемо: средний раздел 220–300 с, доля короче 120 с не выше 10 %, число проходов то же.

3. **Проверка кода** (бесплатно): `npx vitest run --project logic`, `npm run typecheck`, `npm run build`.
   Ожидаемо: хэши инструкции в `tests/unit/prompt.test.ts` переснятые, проверка «без числовых характеристик раздела»
   проходит, остальные тесты без правок.

4. **Слепая проверка качества** (платно, около $0,38 за прогон окон): те же 12 окон, прежний вариант (метка `lbase`,
   «Luna с кадрами») против нового; независимые проверяющие без сведения о происхождении версий.
   Ожидаемо (SC-006): верных фактов не ниже 77,3 %, пропущенных не выше 14 %, тяжёлых ошибок не больше шести.

## Часть 2. После выпуска (приёмка)

Приёмка — только после слияния и сборки Cloudflare: сервис должен быть выпущен.

1. **Согласие на перегенерацию**: владелец называет эфир (последний на канале на день запуска; на 11 октября 2026 —
   2892792614) и принимает цену около $0,15.
2. **Перегенерация**: повторный разбор через интерфейс владельца (или `POST /api/streams/<id>/reparse`).
   Ожидаемо: запись `ready`, документ заменён, знания прежнего разбора ушли целиком (SC-008).
3. **Размер на живом документе**: `section-sizes.mjs <id>`; ожидаемо — медиана 220–300 с, доля короче 2 минут не выше
   10 % (SC-001, SC-002), ни одного раздела выше предела выдачи (SC-005).
4. **Поиск**: 20 вопросов по фактам эфира, нужный раздел в первых пяти результатах не менее чем в 9 случаях из 10
   (SC-007).

Проверки, для которых нужен развёрнутый сервис, в `tasks.md` не пишутся: это приёмочные проверки (`CLAUDE.md`).
