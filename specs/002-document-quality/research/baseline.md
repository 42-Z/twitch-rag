# Точка отсчёта: как разбиралась запись до правок 002

**Дата**: 2026-09-17 | **Спецификация**: [../spec.md](../spec.md) | **Замеры**: [results.md](./results.md)

Точка отсчёта нужна, чтобы после правки было с чем сравнивать. Она снята не отдельным
прогоном сейчас, а взята из замеров, сделанных **до** изменений, — и это не замена
измерения, а его пересказ: прежней инструкции в коде больше нет, и повторить её прогон
можно только из сохранённого текста. Вариант `A-сегодня` стенда брал системную
инструкцию и сборку запроса прямо из `src/shared/openrouter.ts`, то есть точка отсчёта
и есть прежний боевой разбор, а не его пересказ.

## Что было в коде

| | До правок |
|---|---|
| Модель документа | `inclusionai/ling-3.0-flash` |
| Потолок выхода | 32 768 токенов (`max_tokens`) |
| Форма ответа | `{type: "json_object"}` — синтаксис JSON без обязательства по составу полей |
| Разбор ответа | вручную (`parseComposedSections`), причина обрыва не смотрится |
| Рассуждения | не заданы: работа на умолчании каталога, а оно у модели неуправляемо |
| Провайдер | не закреплён и не проверен на поддержку параметров |
| Порядок сообщений | системная инструкция → всё остальное в одном сообщении, строка про участок перед расшифровкой |
| Заголовок площадки | участвует в разборе и показывается человеку |
| Имя документа | не вырабатывается: берётся заголовок трансляции с площадки |
| Сведения о стримере | их нет |
| Повторный разбор | только автоматикой по исчерпанным попыткам; владельцу недоступен |

## Что показывал разбор

Материал тот же, что у остальных замеров: запись `2875806701` канала 5opka, участок
20:00–90:00 (47 770 знаков расшифровки).

| Величина | Значение | Откуда |
|---|---|---|
| Объём документа, 70 мин | 14 729 знаков (31 %) и 9 734 (20 %) в двух прогонах | results.md, §1 |
| Объём документа, 15 мин | 5 160 знаков (47 %) | results.md, §1 |
| Фактов из 25 при сверке | 23 | results.md, §2 |
| Обрывов по потолку | 4 прогона из 8 на участках 20–40 минут дали 0 знаков | results.md, §7 |
| Время прохода | 80–608 с | research.md, §1 |
| Цена прохода | 0,003 $ удачный, 0,007 $ оборванный | results.md, §7 |

Причина обрывов разобрана там же: модель пересказывала себе весь эфир в рассуждении —
123 749 знаков текста рассуждений, — и весь потолок уходил в этот пересказ.

## Что видел человек и ассистент

- В документе первой строкой стоял заголовок с площадки:
  `РАССКАЗЫВАЮ ИСТОРИИ И ЧЁ-ТА ДЕЛАЮ // !донат !приватка !правила !funpay !tornado !тг`.
- В списке разобранного и в выдаче знаний — тот же заголовок: у куска в метаданных поле
  `title` заполнялось им же.
- Мусор распознавания переносился в документ как содержание: «Wolverine на ultra-sit»,
  «Altyazı M.K.», «Топлиса», «Мельчор», «отправляй смерчом» (results.md, §4).

## С чем сравнивать после правок

Сравнение делается не «на глаз», а тем же стендом по трём счётчикам (research.md, §8):

1. сколько в документе следов сбоев распознавания;
2. сколько фактов из списка сохранено — было 23 из 25, падать не должно;
3. сколько раз на неразборчивом месте появилось утверждение, которого нет в записи.

Плюс величины, которые видно и без модели: доля объёма от расшифровки, признак остановки
(`finish_reason`) и цена прохода. Итог сверки — в [results.md](./results.md), раздел 11.
