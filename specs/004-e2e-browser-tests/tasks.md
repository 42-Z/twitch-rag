## Phase 3: User Story 1 - Страница говорит правду о том, что сделал сервис

**Goal**: нажатие кнопки в браузере не обещает работу, которой сервис не начал

**Independent Test**: возврат прежнего поведения кнопки валит проверку

- [X] T007 [US1] Перехват сети в проверке: сервису — только страница и её файлы, реестру и управляющим путям — заглушки с ответами про пропуск
- [X] T008 [US1] Проверка «добавление короткой записи»: страница показывает причину пропуска и не показывает «Запись принята в обработку»
- [X] T009 [US1] Проверка «повторный разбор обрывка»: причина появляется рядом с записью, запись не переезжает в «В обработке»
- [X] T010 [US1] Отделить браузерные проверки от `bun test`: расширение `.e2e.ts` и `testMatch` в настройке
- [X] T011 [US1] Доказать, что проверка ловит ошибку: с возвращённым прежним поведением кнопки прогон падает (SC-001)
- [X] T012 [US1] Сторожевая проверка подставного окружения: сервис для проверок поднят с адресами, ведущими в никуда (SC-002)
